# MIDIeditmobile

Android タブレット向けの、ピアノ専用 MIDI エディタです。Kotlin + Jetpack Compose で構成し、
ピアノロールだけはスタイラスホバーと細かいポインタ制御のため、独自の `View` + `Canvas` で描画・操作しています。
WebView や Web アプリは使用していません。

- パッケージ: `com.pianocanvas.midi`
- アプリ名: MIDIeditmobile
- minSdk 26 / targetSdk 34
- 内蔵音源: 同梱の `app/src/main/assets/piano.sf2`（自前生成・CC0）
- 出力 APK: `app/build/outputs/apk/debug/app-debug.apk`

---

## ビルド

前提: JDK 17 以上、Android SDK Platform 34 / Build-Tools 34。

```bash
./gradlew :app:assembleDebug
```

APK は `app/build/outputs/apk/debug/app-debug.apk` に生成されます。端末へは次のようにインストールできます。

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

テスト:

```bash
./gradlew :app:testDebugUnitTest
```

ユニットテストは MIDI のラウンドトリップ、ランニングステータス、テンポ・拍子の保持、
META（著作権・キー・テキスト）の往復、スナップ／3連符、テンポ・拍子マップ、
同梱 SoundFont のパースなど **30 件**を収録しています。

### GitHub Actions によるリリース

`.github/workflows/android-release.yml` が、ユニットテスト・Lint・APK ビルドを実行し、
タグ push 時は GitHub Release に APK と SHA-256 を添付します。

```bash
git tag v1.0.0
git push origin v1.0.0
```

- `v*` タグ: テスト → Lint → `assembleDebug` → GitHub Release 作成
- 手動実行（Actions タブの **Build and Release APK**）: ビルドのみ行い、APK を Artifacts に保存
- APK はデバッグ署名です。配布用のリリース署名が必要な場合は、署名設定を追加してください

## 画面構成

```
┌──────────────────────────────────────────────────────────┐
│ 曲名 / 自動保存 / 音源状態   再生・停止・ループ   BPM 拍子 │
├──────────────────────────────────────────────────────────┤
│ タブ（複数プロジェクトを開いているときのみ）              │
├────────────┬─────────────────────────────────────────────┤
│  小節ルーラー（タップ／ドラッグで再生位置指定）           │
│  ループ帯（ドラッグで範囲指定）                           │
├────────────┼─────────────────────────────────────────────┤
│            │                                             │
│  ピアノ鍵盤 │              ピアノロール                    │
│  （試聴）   │   グリッド / 音符 / ゴースト / プレイヘッド  │
│            │                                             │
├────────────┴─────────────────────────────────────────────┤
│ 状況に応じたツールバー（未選択時 / 選択時で内容が変化）    │
└──────────────────────────────────────────────────────────┘
```

- 横画面・縦画面の両方に対応。幅 960dp 未満では上部バーを 2 段に切り替えます。
- 上部バーはステータスバーや画面の切り欠き（ノッチ）の下に配置されるため、
  端末側が edge-to-edge 表示を強制しても曲名・再生・メニューが隠れません。
- ピアノロールを最大限広く取るため、常設ボタンは再生系と下部の文脈ツールバーだけに絞っています。
- 主要な操作・ダイアログ・設定項目には Material Icons を付け、文字だけのボタンを減らしています。
- 鍵盤と時間軸は独立してスクロールします（時間軸を動かしても鍵盤は横に動きません）。

## 操作体系

### 指

| 操作 | 動作 |
|---|---|
| 空欄をタップ | 現在の入力長で音符を追加 |
| 空欄をドラッグ | 最初に動いた方向へスクロール（軸固定） |
| 2 本指 | スクロール / 時間・音高のピンチズーム |
| 空欄を長押し | 矩形で複数選択 |
| 音符をタップ | 選択（ダブルタップで削除） |
| 音符を長押し | 選択に追加 / 選択から除外 |
| 音符をドラッグ | 移動（複数選択時はまとめて移動） |
| 音符の端をドラッグ | 長さ変更 |
| ルーラー | 再生位置の指定 |
| ループ帯 | ループ範囲の指定 |

### スタイラス（ホバー対応端末）

| 操作 | 動作 |
|---|---|
| ペンを浮かせる | ゴースト音符 / 対象音符の強調 / 追従ツールバー |
| 空欄をドラッグ | ドラッグした長さで音符を作成 |
| 音符の中央をドラッグ | 移動 |
| 音符の端をドラッグ | 長さ変更（境界はヒステリシス付き） |
| 音符をダブルタップ | その音符を削除（元に戻すで復元） |
| 音符を長押し | 複数選択の追加・解除 |
| ペンの消しゴム | 触れた音符を削除 |
| ホバーツールバーの「編集」 | 数値編集を開く |

ホバー中は編集を確定しません。ゴースト表示とツールバーのみを更新します。
ツールバーはペン先から少し離し、画面端では自動的に内側へクランプされます。
ポインタ位置の微小な変化ではツールバーを再配置しないよう、更新を間引いています。

ホバー非対応端末でも、上記の指操作とペンのタップ／ドラッグで全基本機能を利用できます。
設定で「指で音符を編集」をオフにすると、指はスクロールと選択専用になります。

### 下部ツールバー

- **未選択時**: グリッド、入力長、スナップ ON/OFF、入力ベロシティ、全クオンタイズ、全選択、貼り付け
- **選択時**: 選択解除、長さ、ベロシティ、半音 / オクターブ移調、複製、コピー、カット、
  貼り付け（再生位置へ）、削除、クオンタイズ、選択範囲をループに、数値編集
- **常時**: 前の小節 / 次の小節、縮小 / 拡大 / 全体表示、ループ ON/OFF、設定

### 追従ツールバー（ペン）

- 空欄: 音符追加、入力長、グリッド、入力ベロシティ
- 音符上: 複製、削除、短く、長く、数値編集

## 主な機能

### ピアノロール

- 音符の追加・選択・移動・伸縮・複製・削除（音符のダブルタップでも削除）
- 複数選択（長押し、矩形選択）とグループ移動・複製・削除
- 音高・開始位置・長さ・ベロシティの数値編集
- 小節／拍／グリッド表示、小節番号付きルーラー、ループ帯
- グリッド: 全音符〜32分音符、付点、3連符、OFF
- スナップ ON/OFF、クオンタイズ
- 時間・音高の独立スクロール、ピンチズーム、全体表示、小節単位移動
- 再生ヘッド、自動スクロール ON/OFF、ループ再生

### 音源・再生

- 同梱 SoundFont によるピアノ音源（ポリフォニック、ベロシティ反映）
- 音符タップ／鍵盤タップ／ドラッグ中の試聴
- 再生・一時停止・停止、再生位置指定
- BPM 20〜400、拍子 1〜32 / 1,2,4,8,16,32
- サステインペダル（CC64）に対応
- ループ範囲の指定とループ再生
- 音源読み込み中／完了／エラーを UI に表示
- 外部 SF2 を設定画面から自由に選択（アプリ内へコピーし、再起動後も維持）
- 内蔵音源への再切替（外部ファイルは削除）

### MIDIキーボード入力（USB / Bluetooth LE）

- Android MIDI API による USB / BLE MIDI キーボードの自動検出と接続
- デバイスの接続／切断を自動で追従。「MIDIキーボード入力」から手動切替・検索も可能
- 接続中は鍵盤の弾いた音をそのまま試聴（サステインペダル CC64 にも対応）
- 録音をオンにすると、入力したノートが再生位置（停止中は入力長）でアクティブトラックに記録
- デバイスが見つからない／Android MIDI 非対応の場合は UI にその旨を表示

### 複数プロジェクトとタブ

- プロジェクトは 1 件ごとに別ファイルでアプリ内に自動保存
- 複数を開くと上部にタブが現れ、タブごとに Undo/Redo・選択・ビューポートを保持
- 「プロジェクトを開く」から保存済みプロジェクトの一覧・読み込み・名前変更・削除
- タブと選択中タブ、入力設定は次回起動時に復元
- 旧バージョンの単一自動保存は、初回起動時に 1 プロジェクトへ自動移行

### 共有

- 現在のプロジェクトを `.mid` として書き出し、Android の共有シート（メール・クラウド等）へ送信
- 一時ファイルはアプリのキャッシュ領域に置き、FileProvider 経由で安全に受け渡し

### MIDI META

- 著作権（Copyright）、キー（Key Signature、長調／短調）、作曲者・作詞者・コメントのテキストを編集
- 書き出し時に曲先頭（トラック1）のメタイベントとして反映し、再保存で重複しないよう管理
- 読み込み時は既存のメタイベントから復元

### 外部キーボードショートカット

| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| R / L | MIDI入力の録音 ON/OFF / ループ ON/OFF |
| Esc | 停止 → 選択解除 |
| Home | 再生位置を先頭へ |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直す |
| Ctrl+C / X / V | コピー / カット / 貼り付け |
| Ctrl+A / Ctrl+D | 全選択 / 複製 |
| Delete | 選択したノートを削除 |
| 矢印 | 選択ノートを移動（上下は移調、Shift でオクターブ） |
| Ctrl+S / Ctrl+Shift+S | 保存 / 共有 |
| Ctrl+N / O / E / P | 新規 / 読み込み / 書き出し / プロジェクト一覧 |
| Ctrl+Tab・Ctrl+PageUp/PageDown | タブ切替 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 拡大 / 縮小 / 全体表示 |

### MIDI ファイル

- SAF による `.mid` の読み込み・書き出し（任意の保存先）
- フォーマット 0 / 1 の読み込み
- 複数トラックファイルでは編集対象トラックを選択
- 未対応イベント、SysEx、他トラックのイベントを保持
- テンポ・拍子・プログラムチェンジ・コントロールチェンジ・ピッチベンドを保持
- ノートは編集状態から再生成。書き出し時にテンポと拍子を先頭へ反映
- ファイルマネージャから `.mid` を開く `ACTION_VIEW` に対応

### 保存

- 約 0.65 秒後の自動保存 + バックグラウンド移行時の即時保存
- プロジェクトごとにアプリ専用領域へ JSON で保存し、一時ファイルでアトミックに更新
- 複数プロジェクトをタブで同時に開け、再起動時に開いていたタブ・ビューポート・設定を復元
- MIDI の書き出し先とは完全に分離（元ファイルを勝手に上書きしません）

### Undo / Redo

音符の追加・削除・移動・伸縮・複製・貼り付け・移調・長さ／ベロシティ変更・クオンタイズ、
BPM・拍子変更に対応（最大 60 段）。

## アーキテクチャ

```

├── MainActivity.kt            単一 Activity。ACTION_VIEW と自動保存の起動順を制御
├── model/Model.kt             Note / Track / Project / TempoMap / MeterMap / GridUnit
├── midi/MidiFile.kt           依存ライブラリなしの SMF パーサ・ライタ
├── midi/MidiInputManager.kt   USB / BLE MIDI デバイスの検出・受信
├── audio/
│   ├── SoundFontLoader.kt     SF2 (RIFF/sfbk) パーサ
│   ├── PianoSynth.kt          AudioTrack + 独自ボイス合成（専用レンダースレッド）
│   ├── PlaybackEngine.kt      専用スレッドのトランスポート、ループ、CC64
│   └── AudioEngine.kt         音源の非同期ロードと状態公開
├── data/
│   ├── ProjectStore.kt        自動保存 JSON のエンコード / デコード
│   └── ProjectRepository.kt   複数プロジェクトの保存・一覧・ワークスペース
├── editor/
│   ├── EditorViewModel.kt     編集状態、タブ、Undo/Redo、入出力、再生の司令塔
│   ├── RollHost.kt            ピアノロール ↔ ViewModel の狭いインターフェース
│   └── HoverInfo / 状態定義
└── ui/
    ├── PianoRollView.kt       独自 Canvas 描画・タッチ／ホバー処理
    ├── EditorScreen.kt        全体レイアウト、タブ、ツールバー、SAF
    ├── Dialogs.kt             BPM・拍子・トラック・数値編集・設定・ヘルプ
    ├── ProjectDialogs.kt      プロジェクト一覧・MIDI META・MIDIキーボード
    └── Theme.kt               ダークテーマ
```

- **モデルは不変データ**。編集は新しい `Project` を作り、UI と再生エンジンへ渡します。
- **描画と入力は View が所有**。ドラッグ中はローカルでプレビューし、指を離した時に 1 回だけ
  ViewModel へコミットするため、Undo は 1 ジェスチャ = 1 履歴になります。
- **音声は UI から独立**。再生スケジューラとシンセはそれぞれ専用スレッドで動き、
  UI はアトミックな再生位置だけを読みます。
- **MIDI の未知イベントは `RawEvent` として保持**。ノートオン／オフだけを編集対象にし、
  書き出し時に再生成します。

## 内蔵 SoundFont

`app/src/main/assets/piano.sf2` は `tools/make_piano_sf2.py` でゼロから合成したものです。
第三者製のサンプルデータは含まず、CC0 として同梱しています。再生成する場合:

```bash
python3 tools/make_piano_sf2.py app/src/main/assets/piano.sf2
```

外部 SF2（SoundFont 2.04）も設定画面の「音源」から自由に選べます。
選択したファイルはアプリ専用領域へコピーされるため、元ファイルを移動・削除しても
次回起動時まで選択が維持されます。「内蔵に戻す」でコピーを削除して同梱音源へ戻ります。
SF3 / Ogg 圧縮、ステレオペア、モジュレータ、フィルタ、LFO は対象外です
（読み込み時に無視されます）。

大きめの音源にも対応しています。

- 読み込みはファイルから直接ストリームし、サンプル以外をメモリに載せません
  （以前はファイル全体・サンプル部・デコード後の 3 重にメモリを消費していました）。
- 読み込める上限は端末のヒープから自動決定します（`android:largeHeap` 有効、
  ヒープの約 45%・最大 512MB まで）。目安として 512MB ヒープの端末で約 1 億サンプル
  （FluidR3 級の GM 音源や一般的なピアノ音源）まで読み込めます。
- 上限を超える音源は、必要な量と端末の上限を示すメッセージで失敗します
  （アプリが落ちることはありません）。

## 既知の制限

- MIDI フォーマット 2、SMPTE タイムベースは読み込めません。
- SF2 のステレオサンプルペア、モジュレータ、フィルタ、LFO は適用しません。
- ピアノ 1 トラック編集が基本です。複数トラックは編集対象の切替のみで、
  トラックの追加・削除・並べ替えはできません。
- サステインの新規入力 UI はありません（読み込んだ CC64 の再生・保持、MIDIキーボードの CC64 試聴には対応）。
- MIDIキーボードからの録音はノートのみです。サステインやピッチベンドは記録されません。
- MIDIキーボード入力は端末の Android MIDI API に対応している必要があります。
- META の作曲者・作詞者・コメントは書き出し時に先頭の Text メタイベントへ反映され、
  読み込み時は先頭トラック先頭の Text の順に割り当てられます。
- `assembleDebug` の APK はデバッグ署名です。配布用にはリリース署名の設定が必要です。
- スタイラスホバーは端末のペン対応に依存します。非対応端末では指操作にフォールバックします。

## ライセンス

アプリ本体のコードはこのプロジェクト内の成果物です。
同梱の `piano.sf2` は `tools/make_piano_sf2.py` による生成物で、CC0 として扱えます。
外部から読み込む SoundFont は、その配布元のライセンスに従ってください。
